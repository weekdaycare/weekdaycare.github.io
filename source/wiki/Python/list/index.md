列表可以容纳不同类型的数据

```python
list=[1,2,3,4,5,"上山打老虎"]
print(list)
#输出
[1,2,3,4,5,'上山打老虎']

for a in list #逐个打出列表中的元素
    print(a)
#输出
1
2
3
4
5
上山打老虎

#下标索引
list[0]
1

list[5]
'上山打老虎'

length = len(list)
list[length - 1]
'上山打老虎'

list[-1]
'上山打老虎'
```

## 增

可以使用 `append()`，功能是在列表的**末尾**来添加一个指定的元素，但是单次**只能增加一个元素**

```py
heros = ["钢铁侠","绿巨人"]
heros.append("黑寡妇")
```

当需要单次增加多个元素时，可以考虑使用 `extend()` ，允许你直接添加一个可迭代对象

```py
heros.extend(["雷神","灭霸"])
heros[len(heros):] = ["雷神","灭霸"]
```

{% border 注意 %}

`extend()` 方法的参数必须是一个可迭代对象，新的内容是追加到原列表最后一个元素的后面。

{% endborder %}

## 插

我们使用 `insert(a,b)` 插入，有两个参数，`a` 是待插入的位置，`b` 是待插入的元素

```py
s = [1,3,4,5]
s.insert(1,2) # 在索引下标为1的位置插入2
s.insert(len(s),6) # 在列表末尾插入6，相当于append()
```

## 删

使用 `remove()` 实现删除

```py
heros.remove("灭霸")
```

{% border 注意 %}

1. 如果列表中存在多个匹配的元素，那么它只会删除第一个（下标最小的那个）

2. 如果指定的元素不存在，那么程序就会报错

   {% folding child:codeblock 报错：x not in list %}

   ```py
   Traceback (most recent call last):
       File "<pyshe11#19>"，line 1，in <module>
       	heros.remove("金莲")
   valueError: list.remove(x): x not in list
   ```

   {% endfolding %}

{% endborder %}


若我们需要删除某一位置的元素，可以使用 `pop()` ，它的输入参数即为元素的下标值

```py
heros.pop(2)
# 删除下标为2的元素
```

那要是说我整个列表都不想要了怎么办？`clear()` 出来救场

```py
heros.clear()
# 清空列表中所有元素
```

## 改

列表和字符串最大的区别是列表是可变的，而字符串是不变的。我们使用下标索引法来进行列表元素的替换，用赋值运算符就可以将新的值给替换进去

```py
numbs = [1,2,3,4,5]
numbs[2] = 0

numbs = [1,2,0,4,5]
```

其实现原理为

1. 将赋值号(=) 左边指定的内容删除
2. 将包含在赋值号(=)右边的可迭代对象中的片段插入左边被删除的位置

{% border 注意 %}

若你的下标值超过了列表的长度会报错

```shell
Traceback (most recent call last):
  File "<stdin>", line 1, in <module>
IndexError: list assignment index out of range
```

{% endborder %}

这种方法也仅仅能进行单元素替换，那如何替换多个连续的元素？那当然是列表切片啦

```py
numbs[2:] = [100,200,300] # 将第二个元素后的值统统替换掉
```

## 排序

比如说我们现在有一个由数字组成的列表，我们想从小到大排序，可以使用 `sort()`（太方便了，让我想起了学C的时候排序都要自己冒泡排序，哭死）

```py
nums = [3,1,2,5,5,32,5,2,8,9,7]
# 从小到大排序
nums.sort()
nums = [1, 2, 2, 3, 5, 5, 5, 7, 8, 9, 32]
# 再从大到小排序
nums.reverse()
nums = [32, 9, 8, 7, 5, 5, 5, 3, 2, 2, 1]
```

`reverse()` 的作用是让列表反转，所以如果要让列表从大到小排序需要先 `sort()` 再 `reverse()` ，**直接使用的话会反转列表而不会排序**

## 查找

现在我们又想知道一个列表中一个元素重复了多少次，又可以用 `count()` ，还是上面的 `nums`

```py
nums.count(5)
```

除了查找的元素出现的次数外，我们还可以查找某个元素的索引值，用 `index()`

```py
nums.index(5) # 查找元素5的下标

nums[nums.index(32)] = 0 # 将数值32替换为0
```

{% border 注意 %}

当列表中存在多个相同的值时，`index()` 只会输出第一个值的下标，同样，若列表中不存在该索引值也会报错

{% endborder %}

`index()` 还可以传入其他两个参数，分别为`start` `end`

```py
nums.index(3, 1, 4) # 从下标为1的元素开始查找到下标为4的元素
```

## 嵌套列表

俗称：套娃，又名二维列表

```py
matrix = [[1,2,3],[4,5,6],[7,8,9]]
```

吼，我们现在有一个嵌套列表，那我们怎么访问嵌套列表捏？

```py
# 打印出列表中所有的元素值
for i in matrix:
    for each in i:
        print(each, end=' ')
        
matrix[0][1] # 第一行第二列
```

通过循环语句来创建初始化二维列表

```py
A = [0] * 3
for i in range(3):
    A[i] = [0] * 3
    
# 错误写法
B = [[0] * 3] * 3
```

不能这样写的原因是外层这个 `*` 它并不是拷贝，只是重复的去引用它

## 拷贝列表

这里需要提到的一点是，我们平时使用的赋值运算符并不是拷贝，只是重复的去引用它，python并不会为y单独开辟一份储存空间

```py
x = [1,2,3]
y = x
```

{% image https://bu.dusays.com/2022/12/06/638ee5de3941e.webp width:300px %}

如果我们在这里改变列表中的某一个值，`x,y` 对应的值也会改变

要是我们不想两个变量用同一个储存空间呢？那就使用 `.cpoy()` 吧

### 浅拷贝

```py
y = x.copy()
```

{% image https://bu.dusays.com/2022/12/06/638ee728e8580.webp width:300px %}

当然也可以使用万能的切片语法

```py
y = x[:] # 没有开始也没有结束示意切整个列表
```

以上两种方法处理一维列表是没有问题的，**但是在处理嵌套列表的时候仍会有干扰**

```py
x = [[1,2,3],[4,5,6],[7,8,9]] # 初始化一个二维列表
y = x.copy() # 复制给y
x[1][1] = 0 # 置0
# 输出x和y看看
x = [[1,2,3],[4,0,6],[7,8,9]]
y = [[1,2,3],[4,0,6],[7,8,9]]
```

我们发现即使我只更改了x列表中的一个值，y列表也跟着更改了。这是因为浅拷贝只是拷贝了外层的对象，如果包含嵌套对象的话，那么拷贝的只是其引用。

{% image https://bu.dusays.com/2022/12/06/638ee95e84269.webp width:500px %}

要解决这个问题就需要使用深拷贝

### 深拷贝

实现深拷贝我们要借助到 `copy` 模块，这个模块有两个函数，一个是 `copy` 实现的是浅拷贝，一个是 `deepcopy` 实现的是深拷贝，要使用这个模块我们要先 `import` 导入

```py
import copy
x = [[1,2,3],[4,5,6],[7,8,9]]
y = copy.deepcopy(x) # copy模块中的copy函数，x作为拷贝对象传入
```

如果包含嵌套列表的话，深拷贝也会拷贝每一层嵌套里面的数据，说人话就是会全部复制一份。

## 列表推导式

列表推导式的基本语法是

```py
[expression for target in iterable]
```

列表推导式是使用一组数据来填充的这个列表的，所以使用一个 `for` 循环语句进行搭配，for语句的左侧是一个表达式，相当于一个循环体在经过运算最终才决定存放在列表中的数据

举个例子，现在我们知道一个列表，它里面的数据都是数值，现在我们需要把列表中的数据都乘以2，一般我们都会使用循环，利用下标索引来更新每一个元素的值

```py
a = [1,2,3]
for i in range(len(a)):
    a[i] = a[i] * 2
```

如果使用列表推导式就是

```py
a = [i * 2 for i in a]
```

处理字符串也不在话下

```py
x = [i * 2 for i in "FBI"]
# 输出
x = ['FF', 'BB', 'II']

code = [ord(i) for i in "FBI"] # ord()函数的作用是将单个字符转化为对应的Unicode编码
```

也可以处理二维列表

```py
matrix = [[1,2,3],[4,5,6],[7,8,9]]
# 通过for语句获取矩阵的每一行，然后我们取每一行的row[1]
a = [row[1] for row in matrix] 
# 输出
a = [2,5,8]

# 或者我想提取主对角线上的元素
diag = [matrix[i][i] for i in range(len(matrix))]
# 输出
diag = [1,5,9]

# 提取副对角线上得元素
cidiag = [matrix[i][len(matrix)-i-1] for i in range(len(matrix))]
# 输出
cidiag = [3,5,7]
```

{% border Notice %}

需要知道的是，循环和列表推导式并不完全相同。

循环是通过迭代来逐个修改原列表中的元素，而列表推导式则是直接创建一个新的列表，然后赋值原先的变量名。

从根本上来说这两种操作是不一样的，但是从效果上来说，两种方法都能够满足我们的需求。

{% endborder %}

同时列表推导式在Python解释器中是以更快的C语言的速度来运行的，比使用Python中的pvm虚拟机以步进的速度运行 `for` 循环要快很多。
