## 内置使用

{% note 最新版的Stellar已经默认内置了blobcat&nbsp;1.0版本的捏（大大真的快） %}

### 引入 blobcat 1.0

这是blobcat 1.0版本的表情，2.0版本的表情太多了，俺整理不过来。我是直接吧waline里面的搬过来哩，换了个CDN

在根目录中的 `_config.stellar.yml` 增加

```yaml blog/_config.stellar.yml
tag_plugins:
  # {% emoji %}
  emoji:
    default: 
    blobcat: https://raw.githubusercontent.com/gh/norevi/waline-blobcatemojis@1.0/blobs/%s.png
```

默认的raw线路的速度实在是一言难尽，可以使用公共CDN（自行测试节点速度），例如（列出来的不一定有效，看地区实际情况）

- raw.iqiq.io
- jsd.cdn.zzko.cn
- fastly.jsdelivr.net
- cdn.staticaly.com
- raw.fastgit.org
- gcore.jsdelivr.net
- github.moeyy.xyz

食用方法：ping以上链接，选择速度最快的替换 `raw.githubusercontent.com` 即可

使用示例：{% emoji ablobcatrainbow %}

```md 源代码
{% emoji blobcat ablobcatrainbow %}
```

### 引入 blobcat 2.0

若你想用 `2.0` 的话我建议你这样填写，因为这个仓库里面表情文件后缀不统一，所以你可以分两部分，一部分`png`，一部分`gif`

```yaml blog/_config.stellar.yml
tag_plugins:
  # {% emoji %}
  emoji:
    default: 
    bbpng: https://emoj.ml/blob%s.png
    bbgif: https://emoj.ml/ablob%s.gif
```

2.0 版本blob表情`png`文件有个统一前缀`blob`，`gif`文件有个统一前缀`ablob`，本着少写一点是一点的原则，引用的时候只需要写表情文件名blob后半部分的名称即可

使用示例：{% emoji bbpng enjoy %}{% emoji bbgif attention %}

```md 源代码
{% emoji bbpng enjoy %}{% emoji bbgif attention %}
```
