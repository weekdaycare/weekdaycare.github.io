部署难度还行，直接放官方文档 https://kkapi-doc.vercel.app/ (需翻)

官方文档还是有一点问题的

### 部署kkapi-open

注意vercel的环境变量，官方文档这里有一点问题，如果你使用的是[MongoDB](https://www.mongodb.com/)的话不需要填写 `DATABASE\_USER` 与 `DATABASE_PASSWORD` 。因为 `DATABASE_URL` 中已经配置好了

{% folding open:false color:light 参考环境变量 %}
| 是否必填 | 名称 | 说明 | 示例 |
| :---: | :---: | :---: | :---: |
| ✔ | DATABASE\_URL | mongoDB链接字符串 | `mongodb+srv://<name>:<passowrd>@cluster0.kb5eurr.mongodb.net/?retryWrites=true&w=majority` |
| ✔ | SECRETKEY | jwt加密字符串(随意写) | `xxxxxx`（任意字母+数字） |
|  | DATABASE\_USER | mongoDB用户名 | `root` |
|  | DATABASE\_PASSWORD | mongoDB用户密码 | `root` |
|  | GITHUB\_CLIENT\_ID | GitHub Client ID | `Iv1.1a4e5a689816a636` |
|  | GITHUB\_CLIENT\_SECRET | GitHub Client secrets | `*****e07ab369` |
|  | PORT | 启动端口 | 3000，默认为3000。vercel部署无需此参数 |
{% endfolding %}

### 部署kkadmin-open

> 注意！这里请不要跟随官方文档的用 `github action` 构建 `vercel` 分支部署，我于22/10/6尝试部署最后登录时会报 `error:404` 错误，详见[issue](https://github.com/kkfive/kkadmin-open/issues/3)

1.  进入[kkadmin-open](https://github.com/kkfive/kkadmin-open/)项目，点击 `fork`，仅fork {% mark master %}分支即可

3.  在 vercel 中导入项目

2.  添加环境变量
    
    {% folding open:true color:light 环境变量请填以下这些 %}
	| 是否必填 | 名称 | 说明 | 示例 |
	| :---: | :---: | :---: | :---: |
	| ✔ | VITE\_GLOB\_API\_URL | vercel或者服务器部署的接口地址 | `https://kkapi-open.vercel.app` |
	| ✔ | VITE\_GLOB\_UPLOAD\_URL | lsky文件上传地址 | `https://7bu.top/api/upload` |
	| ✔ | VITE\_GLOB\_UPLOAD\_TOKEN | lsky上传所需要token | `xxxxxx` |
	|  | VITE\_GLOB\_LSKY\_VERSION | lsky版本号，默认V1 | `V2` |
	|  | VITE\_GLOB\_LSKY\_STRATEGY\_ID | strategy\_id |  |

### 其他问题

由于vercel自己分配的域名`vercel.app`最近在国内被dns污染，我建议为你的vercel项目增加一个域名使得在国内你的ispeak也能正常访问(白嫖一个域名即可，像是[Freenom](https://www.freenom.com/)等地方都可以白嫖)

其他按照官方文档即可，若有问题欢迎评论交流
